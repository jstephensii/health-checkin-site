Privacy Policy: Weekly Health Checker

Effective November 12, 2026.

Who uses it

Weekly Health Checker is a personal tool, used only by the owner of this GitHub account to read their own data. It is not offered to anyone else.

What data it reads

With the owner's consent, it uses read-only access to the Google Health API for sleep, activity and exercise, and health metrics and measurements. It never writes to, changes or deletes any Google data.

How the data is used and stored

The data is used only to produce the owner's weekly health summaries. It is stored only on the owner's own computer and in the owner's private storage. It is never sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local files removes all copied data.
